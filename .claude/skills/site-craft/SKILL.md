# Site craft — сайты, которые не выглядят сгенерированными

Владелец (24.10): «очень много дубликатов дизайна, каждый сайт должен быть абсолютно уникальным: свои элементы,
свой шрифт, свои анимации… не спеши, каждая задача на все 100%». Этот навык — как этого добиться и как это проверить.
Перед работой прочитать также `emil-design-eng` (движение), `impeccable/reference/craft-floor.md` (минимум качества),
`playwright-cli` (проверка). Решения владельца важнее всего здесь.

## 1. Что такое слоп (и почему его видно сразу)

Слоп — не «некрасиво», а **узнаваемо-средне**: решение, которое подошло бы любому сайту. Признаки, найденные на
наших же 122 сайтах и в типовой генерации:

| Слоп | Вместо этого |
| --- | --- |
| Герой: заголовок по центру + подзаголовок + две кнопки + картинка справа | Композиция из предмета ниши: у пиццерии — печь/лопата, у клиники — карта приёма, у ювелира — витрина под лупой |
| Все блоки `fade-up 30px, 0.6s, stagger 0.1` | Своя хореография на сайт: один ведущий приём и порядок (см. §4) |
| Карточки `rounded-2xl shadow-lg` сеткой 3×N | Форма из мира бизнеса: чек, бирка, билет, полка, табло, папка с вкладками |
| Один и тот же шрифт-«безопасник» (Inter, Montserrat, Oswald) | Шрифт, который говорит о нише и есть только у этого сайта (§3) |
| Иконки-эмодзи, «✨», градиент фиолетовый→синий | Свои линейные знаки в палитре сайта или ничего |
| Счётчики «10+ лет / 500 клиентов» с набегающими цифрами на каждом сайте | Цифры — только когда это настоящая единица бизнеса (°C печи, карат, мм шва), и подача своя |
| Бегущая строка капсом между блоками | Только если у ниши есть «табло» по смыслу (вокзал, биржа, меню-борд) |
| Анимация всего подряд | Анимируется то, что что-то объясняет или отвечает на действие (Эмиль: «why does this animate?») |
| Тексты «Мы — команда профессионалов», «индивидуальный подход» | Конкретика ниши: процессы, единицы, материалы, сроки |

## 2. Как устроены референсы (из их кода, 24.10)

- **unbelievablycrap.com** — GSAP 3.12.5 + CustomEase + Barba, three.js r159. Глобально `CustomEase.create('osmo','0.625,0.05,0,1')`, `gsap.defaults({ease:'osmo',duration:.6})`, Lenis `lerp .165`.
  Переход страниц — **пиксельная сетка**: 12 колонок квадратов, каждая колонка вспыхивает `0.2s` с перекрытием `0.3`,
  контейнер — ступенчатый `clip-path`. Картинки проявляются **пикселизацией**: 10 шагов от 10 колонок до полного
  разрешения, геометрическая рампа, 90 мс на шаг, `imageSmoothingEnabled=false`, старты разнесены на несколько мс.
  Текст — строки из размытия `blur 11px → 0`, `1600ms`, шаг между строками **14ms** (а не 50–100). Край перехода —
  «рваный»: шум 5 октав добавлен к signed distance до порога (`dispAmp .095, dispScale 12.2, soft .001, grain .29`).
  Шрифт один — PP Supply Sans, 10px капсом, `ls -0.4px`, межстрочный 5–11px: плотный HUD. Палитра: белый, `#393939`, один красный.
  Телефон закрыт «дверью» (`max-width:720px`), класс ставится в `<head>` до первой отрисовки — без вспышки.
- **haoqi.design** — Next + Lenis + three.js r184 шейдеры. Вход: тонкая полоса-прогресс по центру → поле точек-полутонов
  собирает слово «hello» → проявляется 3D-надпись и заголовок капсом. Кривые `cubic-bezier(.66,0,.01,1)` 1.2s (переходы
  блоков), `(.25,1,.5,1)`, `(.22,1,.36,1)`, `(.65,0,.35,1)`. Шрифты: TikTok Sans + tronica-mono капсом для меток.
  Мелочи «живого прибора»: часы GMT, координаты, звук `SOUND[ ]`, тема `THEME[*]`. Финал — гиперпрыжок линий за словами.
- **incredibles.dev** — Nuxt + GSAP + Lenis + OGL + Matter.js. Neue Montreal 300–500 (заголовок 500, `ls -0.02em`,
  межстрочный 0.86), Frama, Supply Mono 12px капсом `ls -0.03em` для кнопок и меток. `transform .8s cubic-bezier(.23,1,.32,1)`,
  `clip-path .6s cubic-bezier(.19,1,.22,1)`, `color .07s ease-out` на ссылках. Приём: **стопка карточек на прокрутке**,
  в каждой — пиксельная фигура (квадраты-ступени) одного розового цвета; заголовок раздела разрезается карточкой.
- **twomuch.studio** — Next + three.js r141: облако 3D-предметов вокруг надутого логотипа, растёт с прокруткой.
  ABC Monument Grotesk 500 везде, `ls -0.03em`, межстрочный ≈ размер. Один кислотный акцент `#E2FF70`. Меню — таблетка.
- **shopify editions winter26** — Rive + Theatre.js + three.js r181 + **anime.js**. Вход: тонкие линии-рамки
  чертятся (`stroke-dashoffset 3s cubic-bezier(.34,.22,.47,.84)`) → в рамке надпись → рамка раскрывается в картину.
  Пружинящие кнопки `cubic-bezier(.34,1.56,.64,1)` .4–.5s. Заголовки разделов — курсивный рукописный буквенный инициал
  (ImperialScript) + гротеск. Рваный край бумаги между сценами. Левая колонка — оглавление с номерами, всегда видна.
- **experience2026.funtech.inc** — three.js r186 **WebGPU**, Rive. Загрузка — экран терминала (VT323, зелёный
  `#8DFFA6` на чёрном): строки «loading models… [#####] 6.4 MB», «compiling shaders 6/9». `cubic-bezier(.16,1,.3,1)`.
- **howtotalktowhitekidsaboutracism.com** — Next + three.js + GSAP: книга-объект падает и раскрывается в 3D, Canela
  (антиква) 14–20px, всё остальное — тишина на чёрном.
- **apple.com** — SF Pro Display ≥ 20px, SF Pro Text < 20px; трекинг зависит от кегля (17px → −0.022em, 12px → −0.01em,
  21px → +0.011em, 24px → +0.009em), межстрочные дробные под ритм (17/25, 12/16, 21/25). Колонки 980/1068/734.
  Навигация `cubic-bezier(.4,0,.6,1)` 0.32s, задержки 0.24s; карусели `opacity, transform .24s ease`; кнопки-капсулы
  `border-radius: 980px`. Блок = один продукт, один заголовок, одна строка, две ссылки — и огромная картинка.

Общее у всех сильных: **один ведущий приём на сайт** (пиксели / облако предметов / книга / рамки / терминал),
**один-два шрифта, но с жёстко настроенным трекингом**, **очень мало цвета** (чёрный/белый/серый + 1 акцент),
**метки моноширинным капсом**, **дорогие мелочи** (часы, координаты, счётчик загрузки по МБ), **ни одной «карточки с тенью»**.

## 3. Отпечаток сайта (обязателен, проверяется скриптом)

У каждого сайта в `content/sites/<slug>.json` поле `craft` (см. `src/lib/craft.ts`):

```json
"craft": {
  "concept": "Печь как сцена: всё растёт из жара устья",
  "display": "…", "text": "…", "label": "…",       // три роли шрифтов; display — уникален в каталоге
  "skeleton": "split-oven",                          // раскладка первого экрана — уникальна
  "signature": "ember-reveal",                       // ведущий приём движения — уникален
  "sequence": ["glow", "dome", "title-lines", "menu-ticket"],  // порядок входа
  "ease": "0.625,0.05,0,1",                          // своя кривая
  "surface": "ticket"                                // форма «предмета» вместо карточек
}
```

`node scripts/craft-check.mjs` падает, если у двух сайтов совпадает `display`, `skeleton` или `signature`, или если пара
(`text`, `label`) повторяется, или шаблон используется больше одного раза. **Новый сайт без отпечатка не выкладывается.**

### Шрифт
- Display — **один на весь каталог** (122 разных). Только с кириллицей (сайты русские) — `@fontsource`/Google Fonts с
  subset cyrillic; без кириллицы браузер молча подставит системный, это хуже любого выбора.
- Выбирать от ниши, не от «красиво»: гротеск-гротеск для ремесла, антиква для ювелирки и права, моноширинный — для
  техники и логистики, рукописный только как акцент-инициал (как у Shopify), трафарет/дисплей — для улицы и спорта.
- Трекинг по кеглю, как у Apple: крупное — в минус (−0.02…−0.04em), мелкое 11–13px капсом — в плюс (+0.04…+0.08em),
  текст 16–18px — около 0. Межстрочный заголовка 0.86–1.0, текста 1.45–1.6.
- Метки — моноширинным или узким капсом (у референсов это всегда так).

### Раскладка первого экрана (skeleton)
Не «по центру». Варианты-основы (каждый сайт берёт свой и меняет под нишу): вертикальное оглавление слева + сцена
справа; слово во весь экран, разрезанное предметом; табло-сетка; терминал/квитанция; книжный разворот; витрина-полка;
карта с точками; стопка листов; HUD с метками по углам; лента-хронология; «окно» в предмет (clip-path); коллаж предметов.

## 4. Движение: хореография, а не эффекты

1. **Один ведущий приём** (`signature`) — то, что запомнят. Остальное — тихое: появление opacity/transform ≤ 0.5s.
2. **Порядок входа** (`sequence`) пишется до кода: что первым (свет, линия, загрузка), что вторым (предмет), потом
   заголовок, потом действие. Шаг между частями 80–160 мс; строки текста — 14–40 мс (unbelievablycrap: 14 мс).
3. **Кривая сайта** — своя, задана одной переменной `--ease` и используется везде. Источники: osmo `0.625,0.05,0,1`,
   haoqi `0.66,0,0.01,1`, expo-out `0.19,1,0.22,1`, Эмиль `0.23,1,0.32,1`, Apple-nav `0.4,0,0.6,1`, spring Shopify
   `0.34,1.56,0.64,1` (только для кнопок/малого).
4. **Библиотеки**: anime.js 4.5 (animejs.com — владелец просил; splitText, svg.createDrawable, stagger с `grid`,
   scrambleText, onScroll), Motion 12/14 для пружин и жестов, WAAPI для простого. three.js/OGL — только если ведущий
   приём в WebGL и окупается (бюджет: < 2 Мп рендера на телефоне, пауза вне экрана).
5. Приёмы из референсов, готовые к переносу: пиксельная сетка-переход; пикселизация картинок; строки из размытия
   (только на мелком количестве строк — blur дорогой); рваный край (шум + порог); рамки, которые чертятся; стопка
   карточек на прокрутке; терминал загрузки; облако предметов; часы/координаты; рукописный инициал.
6. Правила Эмиля обязательны: нажатие `scale(.97)` 100–160 мс; не из `scale(0)`; hover только `(hover:hover)`;
   анимируем transform/opacity/clip-path; выход быстрее входа; `prefers-reduced-motion` — без перемещений, но с opacity.
7. **Без скрипта всё видно.** Прячет только класс, который ставит скрипт; первый экран — CSS с первой отрисовки, а не
   по IntersectionObserver (иначе на медленной сети пустой кадр).

## 5. Тексты
- Название в каталоге — **«Ваша компания»** (владелец, 24.10): сайты — образцы для покупки. Никаких выдуманных имён,
  адресов «ул. Бабура, 77», телефонов реальных людей. Место — «Ваш город», телефон `+998 00 000-00-00`.
- Пишем от бизнеса, конкретно ниши: единицы, материалы, сроки, процесс. Без «команды профессионалов».

## 6. Проверка (не доверять глазам на одном кадре)

```bash
npm run build && (ADMIN_PASSWORD=x setsid npx next start -p 3100 &)
node scripts/craft-check.mjs                 # уникальность отпечатков по каталогу
node scripts/check-site.mjs <slug> <папка>   # ошибки, ширина, кнопки, якоря, меню, логотип
node scripts/check-motion.mjs <slug> <папка> # движение: ничего не застряло скрытым
node scripts/film.mjs <slug> <папка>         # раскадровка входа 0–3 с и прокрутки, компьютер и телефон
```
Смотреть раскадровку целиком: порядок совпадает с `sequence`? нет ли кадра «пусто»? не прыгает ли текст при
подгрузке шрифта? Сравнить с соседями по нише рядом (контактный лист) — если два сайта путаются, не готово.

## 7. Ловушки, которые уже случались

- **Штрих «рисуется» через `pathLength` + `stroke-dasharray` не сочетать с `vector-effect: non-scaling-stroke`**:
  Chrome считает штрих в экранных пикселях, и линия останавливается на полпути (купол Forno, рамка листа
  «Эскиза», пештак «Джезвы»). Рисовать такие рамки — раскрытием `clip-path`, а штрих — только без non-scaling.
- **Наблюдатель не видит элемент с `clip-path` нулевой площади**: прятать надо дочерний слой, а наблюдать —
  родителя (галерея «Каппинга» на телефоне не проявлялась).
- **Анимация на `transform` у элемента, которому transform задаёт раскладку** (лист кольца, флажок табло) —
  перетирает раскладку. Рост — через отдельное свойство `scale`/`translate` или на внутреннем слое.
- **Переводы uz/en хранят пустые `image`** — медиа всегда берётся из основной версии (`mergeTranslation`).
- **`inline-block` в ячейке grid растягивается** — `clip-path` в процентах тогда считает от всей ячейки:
  `justify-self: start`.
- **Значение CSS-переменной по умолчанию — на том же элементе, куда пишет скрипт**, а не на потомке:
  объявление `--sx` на дочернем svg перебивает наследуемое значение, и тени «Сада» стояли на месте.
- **Японские шрифты (Kosugi Maru и др.) ставят кириллицу во всю ширину** — для меток не брать.
- **`craft.concept` не длиннее 200 знаков** — иначе схема не проходит и сайт отдаёт 404 (smartmebel). Схему
  проверяет `scripts/craft-check.mjs`; запускать после каждой правки отпечатка.
- **Свой первый экран — всегда `theme.actor: 'none'`**: иначе общий `NicheActor` рисует поверх свою фигуру.
- **Кадр 0% анимации с `fill: both` виден во время задержки** — если элемент должен появиться позже, в 0% ставить
  `opacity: 0` (бусины карамели, плейхед нот, искры навеса).
- **`counter-reset: x var(--x)` — на том же элементе, где идёт анимация `--x`**, а не на родителе: родитель
  берёт своё значение, и счётчик стоит на конечной цифре с первого кадра.
- **Одна и та же анимация с `steps(1)` и `fill: both` для «загорается позже»** ломается, если подставить
  длительность через переменную; надёжно — `from, to { серое }` на время ожидания без `fill`.
- **Пересобирать только `npm run build`** (не `npx next build`): стили шаблонов генерирует `prebuild`
  (`scripts/seeds.mjs`), иначе проверяется старый CSS.
- **Выкладка atlas: `upload_source_maps: false`** в wrangler.jsonc — карты кода больше 15 МБ, и деплой падает.
  После выкладки KV-кэш страниц живёт ещё ~60 с — проверять `tpl-*` через минуту.
- **Display-шрифт в одном начертании** (многие декоративные) — фальшивый полужирный выключен глобально
  (`font-synthesis-weight: none`). Широкие и декоративные шрифты проверять на самом длинном заголовке
  ««Ваша компания»» и на кнопках (кнопки часто набраны display-шрифтом): Rubik Vinyl, Train One, Reggae One —
  ломали строки или были нечитаемы; в Pochaevsk нет «Я». Шаблоны с заголовком 17–20vw годятся только для узких
  шрифтов.
