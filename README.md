# Atlas — конструктор сайтов уровня студий

Десять шаблонов, десять готовых сайтов для разных ниш и одна админка. Каждый шаблон — отдельный
визуальный мир со своим WebGL-шейдером, кинетической типографикой и ритмом; каждый сайт — с полной
SEO/AEO/GEO-обвязкой, которая собирается из данных, а не пишется руками.

```bash
npm install
npm run dev            # http://localhost:3000 — витрина, /<slug> — сайт, /admin — админка (пароль «admin» в dev)
npm run build && npm start
```

## Как устроено

- **Сайт = один JSON** (`content/sites/<slug>.json`, схема — `src/lib/schema.ts`): тема, данные бизнеса,
  SEO и список секций. Секций 14 типов (первый экран, бегущая строка, о компании, услуги, работы,
  цифры, этапы, отзывы, команда, тарифы, меню, галерея, FAQ, контакты), поля у всех шаблонов одинаковые —
  поэтому шаблон меняется одним кликом без потери содержимого.
- **Шаблон** (`src/templates/<id>/`): `meta.ts` (название, ориентир, тема по умолчанию), `index.tsx`
  (оболочка — шапка, подвал, фон — и фирменные версии секций), `client.tsx` (шейдеры и интерактив),
  `style.css` (всё под `.tpl-<id>`). Секции, которые шаблон не переопределил, рисуются базовой
  семантической разметкой (`src/components/sections.tsx`) и окрашиваются его CSS.
- **Движение** — атрибутами разметки, одна среда на сайт (`src/motion/runtime.tsx`): `data-reveal`,
  `data-split`, `data-parallax`, `data-count`, `data-magnetic`. Lenis — плавная прокрутка, GSAP SplitText —
  строки из-под маски. Без JavaScript всё видно; `prefers-reduced-motion` и ползунок «Анимация» в админке
  выключают движение.
- **WebGL** без библиотек (`src/motion/shader.tsx`): один полноэкранный треугольник, общие uniform'ы
  (время, курсор, прокрутка, скорость, цвета темы), рисует только пока холст в кадре, плотность пикселей
  ограничена. Вместо фото по умолчанию — генеративные иллюстрации в цветах сайта (`src/motion/art.tsx`).
- **Хранилище** (`src/lib/store.ts`): исходники в `content/sites`, правки из админки — в `DATA_DIR/sites`
  (по умолчанию `./data`), загруженные фото — в `DATA_DIR/media`. Работает на любом Node-хостинге и в
  Docker с томом. Для бессерверного хостинга модуль заменяется на KV/БД — интерфейс из пяти функций.

## SEO · AEO · GEO

Всё собирается из одних данных сайта (`src/lib/seo.ts`), поэтому разметка, текст страницы и llms.txt
не расходятся:

- **SEO** — title, description, canonical (свой домен или адрес в конструкторе), Open Graph и Twitter с
  автообложкой `/<slug>/opengraph-image`, иконка, `sitemap.xml` с картинками, `robots.txt`.
- **Разметка schema.org** — организация нужного типа (Restaurant, Dentist, Hotel, LegalService,
  ExerciseGym, RealEstateAgent, Bakery…) с адресом, координатами, часами, `sameAs`; каталог услуг и
  тарифов с ценами, меню (`hasMenu`), отзывы без выдуманных звёзд, `WebSite`, `WebPage`, `BreadcrumbList`,
  `FAQPage`, `HowTo` из этапов.
- **AEO** — сводка-ответ сразу под первым экраном (что, где, для кого, сколько стоит), FAQ всегда в HTML
  (`<details>`), `SpeakableSpecification` для голосовых ассистентов.
- **GEO** — `/<slug>/llms.txt` и `/<slug>/llms-full.txt` (факты, услуги, цены, меню, FAQ), общий
  `/llms.txt`; GPTBot, ClaudeBot, PerplexityBot, Google-Extended и др. разрешены явно.
- В админке — превью выдачи и чек-лист готовности с оценкой (длины, сводка, FAQ, NAP, часы, соцсети).

## Админка

`/admin` — пароль из `ADMIN_PASSWORD` (в продакшене без него админка закрыта; в dev — «admin»).

- список сайтов с оценкой SEO-готовности, создание сайта из любого образца на любом шаблоне, копия;
- редактор: секции (порядок, включение, дублирование, добавление любой из 14), дизайн (шаблон, 6 цветов
  с проверкой контраста, шрифты, сила анимации), SEO с превью выдачи и JSON-LD, данные бизнеса, свои
  домены, сырой JSON; загрузка фото (тип проверяется по байтам, до 8 МБ);
- живое превью сайта на компьютере и телефоне, сохранение по ⌘S.

## Свой домен

Добавьте домен сайту во вкладке «Основное» и направьте DNS на сервер: `src/proxy.ts` отдаёт `example.uz/…`
как `/<slug>/…`, первый домен становится canonical.

## Переменные

См. `.env.example`: `SITE_URL` (публичный адрес конструктора), `ADMIN_PASSWORD`, `ADMIN_SECRET`, `DATA_DIR`.

## Живые сайты на Cloudflare (с 18.10.2026)

- **Конструктор** — воркер `atlas` (OpenNext): https://atlas.genkai.workers.dev, админка владельца конструктора —
  `/admin` с паролем `ADMIN_PASSWORD` (секрет воркера). Правки — D1 `atlas` (таблица `docs`), фото — R2 `atlas-media`.
  Исходные сайты — `content/sites` (в воркер попадают модулем `src/lib/seeds.generated.ts`, `scripts/seeds.mjs`).
- **Сайты** — воркеры-маршрутизаторы `<slug>` (`workers/router/index.js`): адрес `<slug>.genkai.workers.dev`
  или домен заказчика, запросы уходят в `atlas` по service binding, ссылки переписываются на чистые (`/`, `/uz/`).
- **Админка владельца сайта** — `<адрес сайта>/admin`, свой пароль (выдаёт владелец конструктора во вкладке
  «Пароль»; хранится только хэш). Видит только свой сайт, правит тексты на трёх языках, фото, контакты, бота.
- **Заявки в Telegram** — вкладка «Заявки в Telegram»: токен от @BotFather → «Подключить» (сервер ставит вебхук
  `/api/tg/<slug>`) → «Start» у бота по ссылке → пробная заявка. Форма на сайте открывается любой ссылкой `#order`.
- Выкладка: `npm run deploy` (конструктор + все маршрутизаторы), `npm run deploy:routers -- slug1 slug2` — новые сайты.
- Свой домен заказчика: в Cloudflare → воркер `<slug>` → Domains & Routes → добавить домен; в админке сайта
  первым в «Свои домены» поставить этот домен (станет canonical).

## Общее для всех 122 сайтов (22.10.2026)

- **Мобильное меню** (`MobileMenu`, `src/motion/widgets.tsx`) живёт в корне сайта (`.site`), а не в шапке: у
  прилипающей шапки есть transform, у многих шаблонов ещё и backdrop-filter — для `position: fixed` это рамка,
  и меню раскрывалось высотой с шапку (пункты за верхом экрана). У шапки `.atlas-hdr` нет `will-change` по той же
  причине. Крестик закрытия — в самой панели, на месте кнопки шапки; Esc закрывает; прокрутка под меню стоит.
- **Появление блоков — без ожидания React** (`MOTION_BOOT` в `SiteRenderer.tsx`): свой наблюдатель + проверка по
  прокрутке, новые блоки подхватываются сами. Заголовки `data-split` режет GSAP после запуска; не успел за 2,5 с —
  `html.split-late`, заголовки видны как есть и потом не перепрячутся.
- **Уменьшение на телефоне** (`PHONE_SCALE`): своя метка viewport последней, метку Next не правим — иначе React
  при загрузке вставлял свою и ширина страницы скакала прямо во время запуска анимаций.
