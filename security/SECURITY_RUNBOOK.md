# Порядок действий: аудит и инциденты

## Повторный аудит

```bash
npm test                         # 169 регрессионных тестов, без сети
npm run security:audit           # код, данные 122 сайтов, зависимости, секреты, сборка → security/results/
npm run security:audit:live      # то же + живая проверка каждого адреса (только чтение и отклоняемые запросы)
```

Код выхода 1 — есть блокирующее нарушение; список — в конце вывода и в `security/results/SUMMARY.md`
(папка в .gitignore). Запускать после каждой выкладки и после добавления сайтов или шаблонов.
Новый сайт попадает в аудит сам: инструмент берёт список из `content/sites`.

Добавили внешний сервис (счётчик, виджет, видео) — допишите домен в CSP в `next.config.ts`, иначе браузер его
не загрузит. Добавили серверное действие в `admin/actions.ts` — первой строкой `guard()` (только владелец
конструктора) или `canEdit(slug)` (владелец сайта); аудит проверяет это правило.

## Инциденты

**Утёк пароль сайта клиента.** Админка конструктора → сайт → «Пароль» → «Новый пароль». Все прежние входы
этого сайта закрываются сразу. Передайте клиенту новый пароль.

**Утёк общий пароль или подозрение на вход в конструктор.** `npx wrangler secret put ADMIN_PASSWORD` (новый
пароль) — все ваши сессии закрываются. Если мог утечь и `ADMIN_SECRET` — смените и его: закроются все сессии
всех сайтов, а боты клиентов нужно будет переподключить (секрет вебхука и ключ шифрования токенов зависят от
него). Проверьте журнал: Cloudflare → Workers → atlas → Logs (включено observability).

**Испорчен сайт (правка, удаление).** Данные правок в D1: восстановление на момент до инцидента —
`npx wrangler d1 time-travel restore atlas --timestamp=<ISO-время>` (30 дней). Исходные данные всех сайтов
лежат в репозитории (`content/sites`), удалённая правка откатывается к ним.

**Спам заявками в Telegram клиента.** Лимиты: 5 за 10 минут с адреса и 40 заявок (30 заказов) в час на
сайт. Если мало — уменьшите числа в `src/app/api/lead/route.ts` / `order/route.ts` или включите в Cloudflare
Security → WAF → Rate limiting на `/api/lead`, `/api/order`.

**Утёк токен Cloudflare.** Удалите его в профиле Cloudflare, создайте новый с узкими правами
(`EXTERNAL_ACTIONS.md`, п. 2), `npx wrangler secret put CF_API_TOKEN`.

**Уязвимость в зависимости.** `npm audit --omit=dev`; обновить пакет или добавить `overrides` в
`package.json`; `npm test && npm run security:audit`; выкладка `npm run deploy:atlas`.
