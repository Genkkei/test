# Задание: 42 новых шаблона — у каждого сайта своё лицо

Владелец увидел, что сайты на одном шаблоне выглядят одинаково («почему они одинаковые? все должны быть
абсолютно разными»). Каждый сайт ниже переезжает на **свой новый шаблон**. Новый шаблон должен
отличаться от всех 80 существующих не цветом, а **композицией, приёмом и характером**: другой первый
экран, другие разделы, другая сетка, другая шапка, своё движение.

Требования владельца, дословно по смыслу:
- «все объекты должны быть качественными» — нарисованные объекты (SVG-иллюстрации, предметы ниши)
  аккуратные, детальные, с объёмом/светотенью, а не значки из трёх линий;
- «должны быть анимации — Motion, anime.js и т. п.» — в каждом шаблоне живое движение;
- **никакого чёрного фона с красным/оранжевым огнём** — ассоциации с адом. Тёмный фон допустим только
  с холодными/спокойными акцентами (синий, зелёный, золото на тёмно-синем); фон по умолчанию — светлый.

## Как устроен шаблон (смотри примеры: src/templates/sofa, ember, bean, oak, forge)

- Папка `src/templates/<id>/` уже есть с заготовкой и зарегистрирована в `registry.ts`/`meta.ts` —
  **эти два файла не трогай**. Заменяешь `meta.ts`, `index.tsx`, `style.css`, добавляешь `client.tsx`
  ('use client', всё интерактивное) и при желании файлы с рисунками (`art.tsx` и т. п.).
- `index.tsx` экспортирует `template: TemplateDef` = `{ ...meta, Shell, sections }`. Shell — шапка (навигация
  `navLinks(site)`, `MobileMenu`, кнопка `site.nav.cta`), `<main id="top">{children}</main>`, подвал
  (контакты из `site.business`, часы `humanHours`). Секции — свои рендереры для **всех типов секций,
  которые есть у твоего сайта** (`content/sites/<slug>.json` → sections[].type), минимум hero и ещё 4;
  остальные рисуются базовыми (src/components/sections.tsx) и стилизуются твоим CSS.
- Корень сайта получает класс `.tpl-<id>`; все классы — с префиксом `<id>-`; CSS-переменные темы:
  `--bg --fg --accent --muted --surface --line --font-display --font-body`. Глобальных `@property`/
  переменных без префикса не заводить.
- Тексты интерфейса — через `pick(site.lang, { ru, uz, en })` / `ui()`; данные — из секций.
  Ничего не выдумывать о бизнесе.
- Фото — `<Media src alt seed colors kind />` (если фото нет — генеративная заглушка). Свои иллюстрации —
  inline SVG, цвета из переменных темы, без внешних файлов, шрифты только из `src/lib/fonts.ts`.
- Движение: атрибуты среды (`data-reveal`, `data-split`, `data-parallax`, `data-count`, `data-magnetic`) +
  своё в `client.tsx` — **Motion** (`motion/react`), **anime.js** (`animejs` v4: animate, createTimeline,
  stagger, svg.createDrawable, onScroll), GSAP/ScrollTrigger. Всё отключается при
  `prefers-reduced-motion`. Двигать только transform/opacity, без layout-анимаций.
- Первый экран: `<h1>` с заголовком обязательно (рядом автоматически встаёт «герой» ниши — оставь
  немного воздуха справа или над заголовком).
- Без `Math.random()`/`Date.now()` в серверном рендере (гидратация). Магазин (`shop`) и форма заявки уже
  работают через базовые компоненты — если пишешь свой `shop`, используй `AddToCart`/`ShopFilter` из
  `@/components/shop/AddToCart` и ключ `${s.id}:${i}`.
- Телефон: всё в одну колонку, ничего не вылезает по ширине (проверка на 390 px; на телефоне страница
  дополнительно уменьшается до 0.76).

## Сайт

В `content/sites/<slug>.json` поменяй `template` на свой id и `theme` (bg/fg/accent/muted/surface/line,
display/body — из FONTS в src/lib/fonts.ts) под новый характер. Тексты, секции и переводы не трогай.
В `meta.ts` — осмысленные name, inspiredBy, mood, niches, defaultTheme (= та же тема), preview.

## Проверка (обязательно, перед тем как сдать)

1. `npx tsc --noEmit` — без ошибок.
2. Сборка и просмотр в своей рабочей копии: `npm run build`, затем `npx next start -p <твой порт>`,
   скриншоты Playwright (`/opt/node22/lib/node_modules/playwright/index.js`,
   executablePath `/opt/pw-browsers/chromium`, флаги `--use-gl=angle --use-angle=swiftshader
   --enable-unsafe-swiftshader`) страницы `/<slug>` на 1440×900 и iPhone 13, весь сайт по экранам.
   Смотри глазами: ничего не налезает, читаемо, объекты аккуратные, нет ошибок в консоли.
3. Останавливай сервер по PID (не `pkill -f`).
4. Закоммить в своей ветке: только свои папки шаблонов и свои файлы content/sites/<slug>.json.
